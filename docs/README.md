## Intention MVP

Auto Assist doit repondre aux demandes SAV et commerciales recurrentes : disponibilite vehicule, prix d'une vidange, voyant moteur, prise de rendez-vous, horaires et contact conseiller.

## Definition rapide du succes

- L'utilisateur obtient une recommandation ou une prochaine action claire en moins de trois minutes.
- L'assistant pose des questions utiles quand les informations critiques manquent.
- Les limites, hypotheses et incertitudes sont explicites.
- L'equipe peut rejouer le parcours de demo sans dependance fragile.
